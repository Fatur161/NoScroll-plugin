# NO SCROLL

---

## 🇺🇸 English

### Description

**NO SCROLL** is a browser extension that disables horizontal&vertical page scrolling.

It was created for learning browser extension development and for use in specific development and testing scenarios.

### Purpose

- Learning browser extension development
- Testing UI behavior without horizontal&vertical scroll
- Development debugging scenarios

---

## 🇷🇺 Русский

### Описание

**NO SCROLL** — это браузерное расширение, которое отключает горизонтальный&вертикального скролл страницы.

Оно создано в целях изучения разработки браузерных расширений и для использования в некоторых сценариях разработки и тестирования.

### Назначение

- Изучение разработки браузерных расширений  
- Тестирование поведения интерфейсов без горизонтального&вертикального скролла  
- Отладка и разработка UI
